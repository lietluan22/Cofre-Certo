# Cofre Certo — versão simples

Controle de renda fixa, cobertura do FGC e objetivos financeiros em HTML, CSS e JavaScript puro.

## Como rodar

Basta abrir o arquivo `index.html` no navegador. Não precisa instalar nada.

## Funcionalidades

- Cadastro de investimentos em renda fixa.
- Total investido e renda estimada por produto.
- Cálculo de cobertura do FGC por instituição.
- Alerta de valor acima de R$ 250 mil.
- Objetivos financeiros com progresso.
- Dados salvos no navegador.
- Layout responsivo para celular e computador.

## Estrutura

```text
index.html
styles.css
app.js
README.md
```
